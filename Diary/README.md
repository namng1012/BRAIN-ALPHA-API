# Research Diary

Research log for the Brain-Alpha-API project. Three files, one per category, append-only.

| File | Contains |
|---|---|
| `conversation-log.md` | chat summaries, requests, outcomes, files touched, open questions |
| `code-technique.md` | reusable coding patterns, non-trivial fixes, helper functions |
| `methodology.md` | data split policy, normalization, evaluation protocol, research decisions |

Each entry carries a 1–10 importance score. Every assistant turn writes at least one entry; the score is a label for later filtering, not a write gate.
